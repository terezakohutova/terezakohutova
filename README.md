### Marketing & Partnerships, run on AI agents I build myself

I work in e-commerce and fintech marketing across CZ/SK/PL/DE, and I build
the AI agents that do the operational work myself, not just prompt someone
else's.

Every project here follows the same rule: the agent drafts and stages, a
person publishes. No agent in these repos holds a posting credential, a
payment method, or a live-launch switch.

- **[paid-ads-agent-playbook](https://github.com/terezakohutova/paid-ads-agent-playbook)**: runnable Claude Code subagents for Google Ads and Meta Ads, audit through launch. Ships with a sample client and a verified audit run, not just a description of what it would find.
- **[claude-code-architecture-showcase](https://github.com/terezakohutova/claude-code-architecture-showcase)**: the workspace architecture (CLAUDE.md index, feedback rules, hooks, skills, scoped agents) behind the automation I actually run.
- **[ai-marketing-playbook](https://github.com/terezakohutova/ai-marketing-playbook)**: reusable patterns for e-commerce ops (listing generation, cross-platform inventory sync, staged outreach), generalized from a production shop.
